# Security Policy

## Reporting a vulnerability

If you believe you've found a security issue in GetAppNiche — the product
(app.getappniche.com, api.getappniche.com), the MCP server, or anything in
this organization's repositories — please email **yaro@getappniche.com**.

- Please do **not** open a public issue for security reports.
- Include steps to reproduce and the potential impact; we'll acknowledge
  within 48 hours.
- Never post API keys or account data in reports. If you found a leaked
  credential, tell us where — we'll rotate it immediately.

## Scope notes

The repositories in this organization contain public distribution material
(agent skills, docs, examples) and intentionally hold no secrets or
infrastructure code.
